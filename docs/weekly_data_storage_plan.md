## 存储分工

内置盘保留当前工作区、规则/脚本、最近完整运行、活动状态和本地内容归档；磁盘未连接时仍可取数、计算、生成和冻结。本机当前空闲约203 GiB（实际检查时值，会随其他应用变化），当前项目没有立即外移才能运行的容量压力。

移动硬盘作为独立归档副本：复制内容对象、每次manifest、冻结规则/脚本、报告及验证回执。先校验源文件哈希，复制对象，再复制manifest，最后逐文件回读哈希并留下备份回执。写入中断不登记成功，重新连接后只补缺少对象；不使用删除同步或覆盖旧manifest。现在没有指定或选择移动盘路径，所以外部备份尚未执行；现有本地恢复演练不算设备故障备份。

原始新闻/供应商数据保持本地授权使用范围，不把大批原件、凭据或整库自动推送GitHub；Git保存代码、规则及允许发布的报告，Git版本记录不替代行情PIT证据。外置盘文件系统待实际接入后核对现有格式及Mac/未来Windows读写兼容性，本轮不格式化。

## 统一数据契约

| 层 | 保存内容与格式 | 必备约束 |
| --- | --- | --- |
| 原始来源 | API原JSON字节、HTML/PDF原件、请求与响应回执 | 真正provider/URL、请求字段/参数、状态码、开始与读取时间、SHA-256；成功但null单列，不改原值 |
| 标准证券与日历 | 当前JSON登记和逐市场日期数组 | 稳定证券ID、上市地、币种、常用当地基准、有效期；NASDAQ/NYSE日历、KRX/KSE、TWSE明确映射 |
| 标准价格 | 未复权收盘JSON；长期批量增长时可另外派生列式文件 | symbol、session_date、price_basis、currency、close、原件路径/哈希；不填非交易日或缺失日 |
| 标准公司行动 | 带版本的事件JSON | 稳定event_id、事件类型、每股现金十进制字符串、币种、公告/除息/登记/支付日、日期依据；未知可为null，禁止换成0 |
| 版本和时点 | 内容对象+manifest；需要跨期查询时由manifest重建索引 | source_published_at或保守区间、retrieved_at、preserved_at、event/session_date分开；前向修订追加版本，不能回填旧时点 |
| 计算结果 | 日收益、累计收益、RV及资格JSON | 算法与参数版本、输入manifest哈希、窗口、币种、收益小数单位、分红/基准/PIT资格逐项状态 |
| 阅读与图谱 | 同源Markdown/HTML/PDF、JSON Canvas/SVG | 报告周、真实生成时间、原快照引用；修订保留旧稿和依赖，不混入后验价格 |
| 审核与执行 | 原始失败、实际QA、测试、运行token总账 | 失败不删除，阶段分开计量；截图可另层存放，清理必须先确认可重建且无原证据用途 |

现金股利金额在标准事件中保留Decimal可精确还原的字符串；价格保持供应商实际精度，展示层才四舍五入。单日/累计回报内部0.01表示1%，差值展示用百分点。时间使用带时区ISO-8601，交易日只存所属交易所的日期，不能伪造收盘发布时间。JSON写入拒绝NaN/Infinity。未知、空返回、无历史供应、非上市、样本不足、权限/身份错误、资格未通过分别保存。

当前采用JSON原件+SHA-256内容目录和manifest即可覆盖规模，不先搭建数据库服务。需要跨期分析时由标准数据派生SQLite索引或Parquet，原件仍是唯一追溯来源，派生文件不能覆盖原证据。

- `market_vintages.py`：`freeze / verify / asof / restore`；内容去重、追加版本、真实保存时间、拒绝覆盖、恢复后逐文件回读。
- `audit_weekly_storage.py`：只读统计全项目、唯一内容、类别、当期包及1/3/5年情景；不会删除或迁移文件。

旧版归档保留在本期暂存根的`state/market_vault/{objects,manifests}`，供原引用回读；新增每周采集与报告依赖统一写入项目根`state/weekly_data`，不再为每周建立独立归档库。对象名为完整SHA-256，manifest保留原相对路径与版本；同一个原路径的新内容得到新对象，不覆盖前版本。原件和诊断保留现有路径，归档只是可恢复副本，不静默改写既有引用。

示例（运行前指定实际工作根、归档根和已有manifest，不照抄占位路径）：

python3 scripts/market_vintages.py asof --vault /实际工作根/state/market_vault --manifest /实际manifest.json --cutoff 2026-10-19T09:00:00+08:00
